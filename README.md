# ずびずばテレポ 総合版 練習アプリ

FINAL FANTASY XIV 絶妖星乱舞の「ずびずばテレポ」を練習するための、非公式ファンメイド練習アプリです。

このアプリでは、以下の2方式を切り替えて練習できます。

* フィリピン箱式
* 回転寿司式

それぞれ、以下の3モードに対応しています。

* ギミック理解
* 位置確認
* 実践練習

初回表示は「フィリピン箱式 / 実践練習」です。
ブラウザに前回の選択状態が残っている場合は、最後に選んだ方式・モードが表示されます。

## 概要

このアプリでは、ずびずばテレポのデバフ判断と配置選択を練習できます。

デバフは、以下の8パターンを想定しています。

```text
↑↑
↓↓
→→
←←
→↓
←↑
↓←
↑→
```

矢印違いデバフについては、実機録画をもとに、表示順を以下の4パターンに寄せています。

```text
→↓
←↑
↓←
↑→
```

逆順の `↓→ / ↑← / ←↓ / →↑` は、少なくとも確認した録画内では出ていなかったため、出題対象から外しています。

## 基本ルール

各デバフには、2つの矢印が表示されます。
それぞれの矢印には、6秒または9秒の発動タイミングがあります。

例：

```text
→：6秒
↓：9秒
```

位置確認・実践練習では、6秒で発動する矢印の設置位置を先に、9秒で発動する矢印の設置位置を後に選びます。

```text
1クリック目：6秒で発動する矢印の設置位置
2クリック目：9秒で発動する矢印の設置位置
```

同じ矢印の場合は、2か所の位置が合っていれば正解です。
6秒と9秒の順番は問いません。

## 方式切り替え

総合版では、画面上部のボタンから以下の方式を切り替えられます。

```text
フィリピン箱式
回転寿司式
```

方式を切り替えても、現在選んでいるモードは維持されます。

## モード切り替え

画面上部のボタンから、以下の3モードを切り替えられます。

```text
ギミック理解：矢印や配置ヒントを見ながら、処理の対応関係を確認する練習
位置確認：元ハード相当。無地マスから、6秒 → 9秒の順に設置位置を選ぶ練習
実践練習：位置確認をベースに、3カウントと制限時間つきで選ぶ練習
```

# 実践練習モード

実践練習は、フィリピン箱式・回転寿司式の両方に対応しています。

## 流れ

実践練習では、スタート後に配置図中央へ大きくカウントが表示されます。

```text
3 → 2 → 1
```

3カウント終了後、左右のデバフが表示され、6秒デバフ側の制限時間が始まります。

```text
6秒バー：1回目の選択時間
3秒バー：2回目の選択時間
```

6秒バーが0になった時点では、まだ正解は表示されません。
続けて3秒バーが0になり、9秒デバフの制限時間が終わったあとに正誤判定と正解が表示されます。

正解表示では、正解マスが緑の枠で囲まれ、先デバフの答えには `①`、後デバフの答えには `②` が表示されます。

正解は約3秒表示されます。
連続モードの場合は、その後に次の3カウントが始まり、次の問題へ進みます。
次の3カウントが始まると、前問の左右デバフ表示は非表示になります。

## 操作ボタン

実践練習では、以下の操作ができます。

```text
連続モード
一問ごとモード
スタート
一時停止
次の問題
同じ問題をもう一度
一問前に戻る
```

### 連続モード

正解表示のあと、自動で次の3カウントが始まり、次の問題へ進みます。

### 一問ごとモード

正解表示のあと、自動では次へ進みません。
必要に応じて「次の問題」または「同じ問題をもう一度」を押して進めます。

### 一時停止

実践練習中に一時停止できます。
再開すると、停止した時点から続きます。

# フィリピン箱式

## フィリピン箱式：ギミック理解

フィリピン箱式のギミック理解では、配置図上の候補を見ながら、デバフと設置位置の対応を確認します。

矢印違いは、以下のように担当エリアを決めます。

```text
←↑：左上
↑→：右上
↓←：左下
→↓：右下
```

担当エリアに入ったら、ボスを見たときに自分の担当エリアが画面左下に来るようにカメラを向けます。
その見え方で、6秒 → 9秒の順に処理します。

### 同じ矢印

同じ矢印は、専用の固定配置に置きます。

```text
↓↓：左上側
←←：右上側
→→：左下側
↑↑：右下側
```

同じ矢印の場合は、2つの設置位置が同じレーン内に並ぶため、秒数による順番は本質的には関係ありません。

## フィリピン箱式：位置確認

フィリピン箱式の位置確認では、配置図上の候補から、実際に矢印を置く位置を順番に選びます。

```text
1クリック目：6秒で発動する矢印の設置位置
2クリック目：9秒で発動する矢印の設置位置
```

矢印違いの場合は、6秒 → 9秒の順番が正解判定に使われます。

同じ矢印の場合は、2か所の位置が合っていれば、順番は不問です。

## フィリピン箱式：実践練習

フィリピン箱式の実践練習では、位置確認と同じ配置選択を、3カウントと制限時間つきで練習します。

6秒デバフの制限時間内に1回目、続く3秒の制限時間内に2回目を選べればOKです。

## フィリピン箱式のカメラ基準

矢印違いの処理では、以下のカメラ基準を想定しています。

担当エリアに入ったあと、ボスを見たときに自分の担当エリアが画面左下に位置するようにカメラを向けます。

この状態にすると、各担当エリアでの処理を「左右の移動」として判断しやすくなります。

# 回転寿司式

## 回転寿司式：ギミック理解

回転寿司式のギミック理解では、表示されたデバフに対応する配置を見ながら、矢印と設置位置の関係を確認します。

フィリピン箱式とは異なり、4隅の担当エリアではなく、回転寿司式の配置図に従って位置を判断します。

## 回転寿司式：配置メモ

回転寿司式では、以下のように矢印を配置します。

```text
上：→ → → → ↓
右：↓ ↓ ↓ ↓ ←
下：↑ ← ← ← ←
左：→ ↑ ↑ ↑ ↓
```

ギミック理解では、この配置のうち、出題された2矢印の組み合わせに対応する位置を確認します。

## 回転寿司式：出題対象

回転寿司式でも、出題対象は以下の8パターンです。

```text
↑↑
↓↓
→→
←←
→↓
←↑
↓←
↑→
```

矢印違いの逆順である以下の4パターンは、出題対象から外しています。

```text
↓→
↑←
←↓
→↑
```

## 回転寿司式：位置確認

回転寿司式の位置確認では、元ハード相当の無地マスから、実際に置く位置を選びます。

```text
1クリック目：6秒で発動する矢印の設置位置
2クリック目：9秒で発動する矢印の設置位置
```

矢印違いの場合は、6秒 → 9秒の順番が正解判定に使われます。

同じ矢印の場合は、2か所の位置が合っていれば、順番は不問です。

## 回転寿司式：実践練習

回転寿司式の実践練習では、位置確認と同じ無地マス選択を、3カウントと制限時間つきで練習します。

6秒デバフの制限時間内に1回目、続く3秒の制限時間内に2回目を選べればOKです。

# 正誤判定について

## 矢印違い

矢印違いでは、表示されている左右のデバフと秒数を見て、6秒 → 9秒の順に設置位置を選びます。

例：

```text
左デバフ：↑ 9秒
右デバフ：← 6秒
```

この場合、右側のデバフが先に発動するため、位置確認・実践練習では右側のデバフに対応する位置を先に選ぶ必要があります。

## 同じ矢印

同じ矢印では、2つの設置位置が合っていれば正解です。
6秒と9秒の順番は問いません。

対象：

```text
↑↑
↓↓
→→
←←
```

# 成績表示について

成績は、ギミック理解・位置確認・実践練習のすべてで反映されます。

反映タイミングは以下です。

```text
ギミック理解：答え合わせを押したとき
位置確認：答え合わせを押したとき
実践練習：9秒デバフ側の制限時間が終わり、正解表示に入ったとき
```

現在の成績は、方式ごとの合算です。

```text
フィリピン箱式：ギミック理解 / 位置確認 / 実践練習を合算
回転寿司式：ギミック理解 / 位置確認 / 実践練習を合算
```
