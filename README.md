# ずびずばテレポ 総合版 練習アプリ

FINAL FANTASY XIV 絶妖星乱舞の「ずびずばテレポ」を練習するための、非公式ファンメイド練習ツールです。

このツールでは、以下の2方式を切り替えて練習できます。

* フィリピン箱式
* 回転寿司式

それぞれ、ノーマル / ハードの練習に対応しています。

## 概要

このアプリでは、ずびずばテレポのデバフ判断と配置選択を練習できます。

デバフは、以下の8パターンを想定しています。

```text
↑↑
↓↓
→→
←←
→↓
←↑
↓←
↑→
```

矢印違いデバフについては、実機録画をもとに、表示順を以下の4パターンに寄せています。

```text
→↓
←↑
↓←
↑→
```

逆順の `↓→ / ↑← / ←↓ / →↑` は、少なくとも確認した録画内では出ていなかったため、出題対象から外しています。

## 基本ルール

各デバフには、2つの矢印が表示されます。
それぞれの矢印には、6秒または9秒の発動タイミングがあります。

例：

```text
→：6秒
↓：9秒
```

ハードでは、6秒で発動する矢印の設置位置を先に、9秒で発動する矢印の設置位置を後に選びます。

同じ矢印の場合は、2か所の位置が合っていれば正解です。
6秒と9秒の順番は問いません。

## 方式切り替え

総合版では、画面上部のボタンから以下の方式を切り替えられます。

```text
フィリピン箱式
回転寿司式
```

ノーマル / ハードの切り替えは、それぞれの方式内のボタンから行います。

# フィリピン箱式

## フィリピン箱式：ノーマル

フィリピン箱式のノーマルでは、最終的な担当エリアやレーンを選ぶ練習をします。

4隅の配置図を見ながら、正しい楕円またはボタンを選びます。

### 矢印違い

矢印違いは、以下のように担当エリアを決めます。

```text
←↑：左上
↑→：右上
↓←：左下
→↓：右下
```

担当エリアに入ったら、ボスを見たときに自分の担当エリアが画面左下に来るようにカメラを向けます。
その見え方で、6秒 → 9秒の順に処理します。

### 同じ矢印

同じ矢印は、専用の固定配置に置きます。

```text
↓↓：左上側
←←：右上側
→→：左下側
↑↑：右下側
```

同じ矢印の場合は、2つの設置位置が同じレーン内に並ぶため、秒数による順番は本質的には関係ありません。

## フィリピン箱式：ハード

フィリピン箱式のハードでは、配置図上の候補から、実際に矢印を置く位置を順番に選びます。

```text
1クリック目：6秒で発動する矢印の設置位置
2クリック目：9秒で発動する矢印の設置位置
```

矢印違いの場合は、6秒 → 9秒の順番が正解判定に使われます。

同じ矢印の場合は、2か所の位置が合っていれば、順番は不問です。

## フィリピン箱式のカメラ基準

矢印違いの処理では、以下のカメラ基準を想定しています。

担当エリアに入ったあと、ボスを見たときに自分の担当エリアが画面左下に位置するようにカメラを向けます。

この状態にすると、各担当エリアでの処理を「左右の移動」として判断しやすくなります。

# 回転寿司式

## 回転寿司式：ノーマル

回転寿司式のノーマルでは、表示されたデバフに対応する楕円を選ぶ練習をします。

フィリピン箱式とは異なり、4隅の担当エリアではなく、回転寿司式の配置図に従って、対応する楕円を選びます。

ノーマルでは、矢印1個ずつではなく、対応する楕円を選べれば正解です。

## 回転寿司式：配置メモ

回転寿司式では、以下のように矢印を配置します。

```text
上：→ → → → ↓
右：↓ ↓ ↓ ↓ ←
下：↑ ← ← ← ←
左：→ ↑ ↑ ↑ ↓
```

ノーマルでは、この配置のうち、出題された2矢印の組み合わせに対応する楕円を選びます。

## 回転寿司式：出題対象

回転寿司式でも、出題対象は以下の8パターンです。

```text
↑↑
↓↓
→→
←←
→↓
←↑
↓←
↑→
```

矢印違いの逆順である以下の4パターンは、出題対象から外しています。

```text
↓→
↑←
←↓
→↑
```

## 回転寿司式：ハード

回転寿司式のハードでは、矢印なしの無地マスから、実際に置く位置を選びます。

```text
1クリック目：6秒で発動する矢印の設置位置
2クリック目：9秒で発動する矢印の設置位置
```

矢印違いの場合は、6秒 → 9秒の順番が正解判定に使われます。

同じ矢印の場合は、2か所の位置が合っていれば、順番は不問です。

---

# 正誤判定について

## 矢印違い

矢印違いでは、表示されている左右のデバフと秒数を見て、6秒 → 9秒の順に設置位置を選びます。

例：

```text
左デバフ：↑ 9秒
右デバフ：← 6秒
```

この場合、右側のデバフが先に発動するため、ハードでは右側のデバフに対応する位置を先に選ぶ必要があります。

## 同じ矢印

同じ矢印では、2つの設置位置が合っていれば正解です。
6秒と9秒の順番は問いません。

対象：

```text
↑↑
↓↓
→→
←←
```

---

# モード

このアプリには、以下のモードがあります。

```text
ノーマル：レーンや担当エリアを選ぶ確認用
ハード：矢印の設置位置を6秒 → 9秒の順に選ぶ実戦寄り練習
```

方式ごとに、ノーマル / ハードを切り替えて練習できます。

# 注意

このツールは個人作成の非公式ファンメイド練習ツールです。
攻略法や処理方法は、使用する固定・PT・マクロによって異なる場合があります。

また、矢印違いデバフの表示順については、自分の録画確認をもとに実機寄せしていますが、全パターンを網羅的に保証するものではありません。
