モード説明

ギミック理解：元ハードの配置をベースに、マスの中に矢印・場所ヒントを出します。

位置確認：元ハード相当。矢印なしのマスから6秒→9秒の順に選びます。

実践練習：3カウント後、6秒バー→3秒バーで回答します。遅デバフ終了後に正解を3秒表示します。

出題対象

同じ矢印：↑↑ / ↓↓ / →→ / ←←

矢印違い：→↓ / ←↑ / ↓← / ↑→

逆順の ↓→ / ↑← / ←↓ / →↑ は出題対象から外しています。
